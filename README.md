# 📊 Dashboard de Vendas — Excel

Dashboard interativo desenvolvido em Excel para análise de performance de vendas, com KPIs, alertas automáticos de risco e visualizações gráficas.

![Status](https://img.shields.io/badge/status-concluído-brightgreen)
![Excel](https://img.shields.io/badge/tool-Excel-217346?logo=microsoft-excel&logoColor=white)

## 🎯 Sobre o projeto

Este dashboard consolida dados de vendas em um painel único, permitindo identificar rapidamente tendências, concentração de risco em produtos e desempenho de vendedores — sem a necessidade de cruzar múltiplas planilhas manualmente.

## ✨ Funcionalidades

- **Filtro dinâmico por mês** — visualize dados de qualquer período ou o total consolidado
- **KPIs principais**:
  - Faturamento total
  - Quantidade de produtos vendidos
  - Ticket médio
  - Melhor vendedor
- **Alerta de concentração de risco** — identifica automaticamente quando um único produto representa uma fatia desproporcional do faturamento
- **Desempenho por produto** — ranking com faturamento e % de participação
- **Faturamento por vendedor** — tabela e gráfico comparativo
- **Vendas por categoria** — visão consolidada por categoria de produto
- **Evolução mensal do faturamento** — série histórica mês a mês

## 🧠 Principais insights do painel

- O produto **Notebook Pro 14** representa **52%** do faturamento total do período, indicando alta dependência de um único item e um ponto de atenção para diversificação de portfólio.
- A categoria **Eletrônicos** concentra a maior parte da receita.
- **Ana Souza** lidera o ranking de vendedores em faturamento gerado.

## 🛠️ Tecnologias utilizadas

- Microsoft Excel
  - Tabelas dinâmicas
  - Fórmulas (SOMASE, PROCV/ÍNDICE+CORRESP, formatação condicional)
  - Gráficos nativos
  - Segmentação de dados (filtro por mês)


## 🚀 Como usar

1. Faça o download do arquivo `.xlsx`
2. Abra no Microsoft Excel (ou Excel Online)
3. Use o filtro "Filtrar por Mês" no topo para explorar os dados por período
4. Todos os indicadores, tabelas e gráficos se atualizam automaticamente
